# SafaQrcode Support

Thank you for using SafaQrcode — a Safari extension that generates a QR code for the current webpage.

## Getting started

1. Open any webpage in Safari.
2. Click the SafaQrcode extension icon in the toolbar (macOS) or tap it in the share/size menu (iOS).
3. The popup shows a QR code for the current page. Scan it with your phone camera, or use **Copy URL** / **Download QR Code**.

## FAQ

**Q: The popup says "Could not read the current page URL."**
A: This happens on pages Safari doesn't expose the URL for (e.g. internal Safari pages). Try a regular webpage.

**Q: Can I use SafaQrcode on internal pages like the start page?**
A: Only standard web pages (http/https) can be converted to a QR code.

**Q: Does SafaQrcode upload anything?**
A: No. Everything, including QR generation, runs entirely on your device. See the [Privacy Policy](privacy-policy.md).

# SafaQrcode 支持

感谢使用 SafaQrcode——一款为当前网页生成二维码的 Safari 扩展。

## 快速上手

1. 在 Safari 中打开任意网页。
2. 点击 Safari 工具栏中的 SafaQrcode 图标（macOS），或在分享/字号菜单中点击它（iOS）。
3. 弹窗会显示当前页面的二维码。用手机相机扫描即可，也可以点击「复制网址」或「下载二维码」。

## 常见问题

**问：弹窗提示「无法读取当前页面网址。」**
答：这种情况通常出现在 Safari 不提供网址的页面上（如 Safari 内置页）。请换成普通网页。

**问：能对 Safari 起始页等内置页面生成二维码吗？**
答：只能对标准网页（http/https）生成二维码。

**问：SafaQrcode 会上传数据吗？**
答：不会。所有操作（包括二维码生成）都在你的设备上本地完成。详见[隐私政策](privacy-policy.md)。
